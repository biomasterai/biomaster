# BioMaster Visual System · 2026-09-11

Visual thesis: a calm research instrument with warm paper, charcoal ink and the approved yellow-green Loop B identity; use precise lines and generous type to connect a dense product workspace to an editorial brand.

Content plan: brand-led opening → logo and foundations → working Chat / Notebook / Team design specimens → components and data states → campaign templates → implementation handoff. The handbook is Chinese; public-facing specimens are English.

Interaction thesis: a brief opening entrance; sticky chapter navigation; light/dark and workspace transitions with keyboard control. Honor reduced motion and avoid perpetual decorative motion.

Scope: an independent design system and UI reference, not a migration of the current application. Logo assets are byte-identical copies of the approved originals. Product content is illustrative. Workspace types are separate projects, never a switch that converts the current project.
